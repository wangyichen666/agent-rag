# 08 环境与依赖清单

> 本文档汇总 agent-rag 系统运行所需的全部软件、模型与硬件，并给出三档配置（最小联调 / 标准 / 生产）与安装命令速查。
> 部署首选 Docker Compose（见根目录 `docker-compose.yml`），本文档供本地开发与离线/私有化部署参考。

## 1. 三档配置总览

| 类别 | 最小联调（无模型，验证链路） | 标准（单机可用） | 生产（多副本） |
|---|---|---|---|
| 基础设施 | MySQL + MinIO + InMemory 向量库 | + Milvus | + Milvus 集群 + Redis |
| Embedding/Rerank | 关闭（FakeEmbedder） | BGE-M3 + bge-reranker（GPU 或 CPU） | GPU 副本组 |
| LLM | 云端 API | 云端 API 或本地 vLLM | 本地 vLLM 或 API 网关 |
| GPU | 不需要 | 推荐 1 张 T4/3060 | 按并发扩 |
| 适用 | 联调、单元测试、演示 | 小团队日常 | 企业生产 |

> 最小联调模式启动命令：
> `RAG_VECTOR_STORE=memory RAG_EMBEDDING_ENABLED=false RAG_RERANKER_ENABLED=false python -m app.main`

## 2. 基础设施中间件

| 组件 | 版本 | 用途 | 替代方案 |
|---|---|---|---|
| **MySQL** | 8.0+ | 业务数据（用户/知识库/文档/会话/消息） | PostgreSQL |
| **MinIO** | 最新 | 文档对象存储（兼容 S3 协议） | 阿里云 OSS / AWS S3 |

| Redis（二期） | 7.x | Embedding/检索缓存、限流 | — |

## 7. 模型权重清单（关键，需单独下载）

模型权重不随代码分发，首次启动时由 FlagEmbedding 自动从 HuggingFace 拉取（需联网）。离线/私有化部署需手动下载。

| 模型 | 用途 | 体积 | HuggingFace 路径 | 国内镜像 |
|---|---|---|---|---|
| **BGE-M3** | Embedding（稠密+稀疏） | ~2.2GB | `BAAI/bge-m3` | `hf-mirror.com/BAAI/bge-m3` |
| **bge-reranker-v2-m3** | Rerank 精排 | ~2.2GB | `BAAI/bge-reranker-v2-m3` | `hf-mirror.com/BAAI/bge-reranker-v2-m3` |

### 离线下载方式

```bash
# 方式一：huggingface-cli（推荐，断点续传）
pip install -U huggingface_hub
export HF_ENDPOINT=https://hf-mirror.com   # 国内加速
huggingface-cli download BAAI/bge-m3 --local-dir ./models/bge-m3
huggingface-cli download BAAI/bge-reranker-v2-m3 --local-dir ./models/bge-reranker-v2-m3

# 方式二：git lfs（完整克隆）
git lfs install
git clone https://hf-mirror.com/BAAI/bge-m3 ./models/bge-m3
```

下载后通过环境变量指定本地路径，避免联网拉取：

```bash
RAG_EMBEDDING_MODEL_NAME=/data/models/bge-m3
RAG_RERANKER_MODEL_NAME=/data/models/bge-reranker-v2-m3
```

## 8. LLM 服务

### 8.1 云端 API（推荐起步，零运维）

| 提供商 | 模型示例 | 协议 | 配置 |
|---|---|---|---|
| DeepSeek | deepseek-chat | OpenAI 兼容 | `RAG_LLM_BASE_URL=https://api.deepseek.com` |
| 通义千问 | qwen-plus | OpenAI 兼容 | `RAG_LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1` |
| OpenAI | gpt-4o | OpenAI | `RAG_LLM_BASE_URL=https://api.openai.com/v1` |

> 配置项：`RAG_LLM_API_KEY`、`RAG_LLM_MODEL`。

### 8.2 本地部署（数据不出网）

| 方案 | 适用 | 显存 | 说明 |
|---|---|---|---|
| **vLLM**（推荐） | 生产、高吞吐 | 见下 | OpenAI 兼容协议，PagedAttention |
| Ollama | 轻量、单机 | 较低 | 简单但吞吐不如 vLLM |

本地 LLM 模型选型（Qwen2.5 系列，中文好）：

| 模型 | 量化 | 显存（含 KV cache） | 适用 |
|---|---|---|---|
| Qwen2.5-7B-Instruct | int4 | ~8GB | T4/3060 16G |
| Qwen2.5-14B-Instruct | int4 | ~12GB | 4090/A10 24G |
| Qwen2.5-32B-Instruct | int4 | ~24GB | A100 40G |

vLLM 启动示例：

```bash
pip install vllm
vllm serve Qwen/Qwen2.5-14B-Instruct \
  --port 8080 \
  --max-model-len 8192 \
  --gpu-memory-utilization 0.9
# 对应配置：RAG_LLM_BASE_URL=http://127.0.0.1:8080/v1  RAG_LLM_API_KEY=EMPTY
```

## 9. 硬件需求

### 9.1 纯 API 模式（LLM 走云端）

| 组件 | 最低 | 推荐 |
|---|---|---|
| CPU | 4 核 | 8 核 |
| 内存 | 8GB | 16GB |
| GPU | 不需要（CPU 也能跑 Embedding/Rerank，慢 10-20x） | T4 16G / RTX 3060 12G |
| 磁盘 | 50GB SSD | 100GB SSD |

> 一张 T4 即可覆盖 BGE-M3 + bge-reranker 推理，全系统门槛很低。

### 9.2 本地 LLM 模式

| 模型规模 | 推荐 GPU | 说明 |
|---|---|---|
| 7B int4 | T4 16G / RTX 3060 12G | 入门 |
| 14B int4 | RTX 4090 24G / A10 24G | 推荐 |
| 32B+ | A100 40G/80G | 高并发 |

### 9.3 Milvus 内存估算

```
单 chunk 存储 ≈ 6~8KB（dense 1024×4B + 原文 + 稀疏 + 索引放大）
100 万 chunk ≈ 7~8GB 内存（HNSW 需全量加载）
```

## 11. 安装命令速查（macOS 本地开发）

```bash
# 基础设施（推荐 Docker Compose 一键起）
cd /Users/pilot/Desktop/agent-rag
docker compose up -d mysql minio etcd milvus

# Python 端
cd agent-rag-python
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install torch FlagEmbedding        # 用真实模型时
cp .env.example .env                   # 按需修改
python -m app.main

# Java 端
cd ../agent-rag-java
# 先建库：执行 src/main/resources/sql/schema.sql
mvn spring-boot:run

# 前端
cd ../agent-rag-front
npm install
npm run dev    # http://localhost:5173
```
