>

> ```bash
> curl -s https://api.siliconflow.cn/v1/embeddings \
>   -H "Authorization: Bearer $RAG_SILICONFLOW_API_KEY" \
>   -H "Content-Type: application/json" \
>   -d '{"model":"Qwen/Qwen3-Embedding-0.6B","input":"测试","encoding_format":"float"}'
> # → 返回 1024 维向量 ✅
>
> curl -s https://api.siliconflow.cn/v1/rerank \
>   -H "Authorization: Bearer $RAG_SILICONFLOW_API_KEY" \
>   -H "Content-Type: application/json" \
>   -d '{"model":"Qwen/Qwen3-Reranker-0.6B","query":"测试","documents":["文档1","文档2"],"top_n":2,"return_documents":false}'
> # → 返回 relevance_score 排序 ✅
> ```
