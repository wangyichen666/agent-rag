## 3. 环境准备

### 3.1 Python 与包管理

agentscope 2.0 要求 **Python ≥ 3.11**。推荐用 `uv` 管理虚拟环境（比 pip 快很多）：

```bash
# 安装 uv（macOS/Linux）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 在桌面建一个工作区
mkdir -p ~/Desktop/agent-lab && cd ~/Desktop/agent-lab

# 创建虚拟环境
uv venv --python 3.12
source .venv/bin/activate

# 安装 agentscope（固定 2.0.4，和 QwenPaw 一致）
uv pip install "agentscope==2.0.4"
```

> 也可以用 `pip`，但本教程示例一律用 `uv pip`。

### 3.2 模型 API Key

教程默认用 **DashScope（通义 Qwen）**，国内最易获取：

1. 到 [阿里云百炼控制台](https://bailian.console.aliyun.com/) 开通，拿一个 API Key。
2. 设置环境变量：

```bash
export DASHSCOPE_API_KEY="sk-xxxxxxxxxxxxxxxx"
```

可选：如果你有 Claude / OpenAI 的 key，周里会给「换 provider」对照示例，分别设 `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` 即可。没有也不影响主线。

## 4. 跑通第一个 Agent（验收环境）

把下面这段保存为 `code/w00/hello_agent.py`（先建 `code/w00/` 目录）。

```python
# code/w00/hello_agent.py
# 环境验收：跑通 agentscope 2.0 第一个能调工具的 Agent
import asyncio
import os

from agentscope.agent import Agent
from agentscope.credential import DashScopeCredential
from agentscope.formatter import DashScopeChatFormatter
from agentscope.message import UserMsg
from agentscope.model import DashScopeChatModel
from agentscope.tool import Bash, Read, Toolkit


async def main() -> None:
    # 1. 模型：默认 DashScope，stream=True 才能拿到流式事件
    model = DashScopeChatModel(
        credential=DashScopeCredential(
            api_key=os.environ["DASHSCOPE_API_KEY"],
        ),
        model="qwen-plus",
        stream=True,
    )

    # 2. 工具：先给它一个 Bash 和一个 Read 兜底
    toolkit = Toolkit(tools=[Bash(), Read()])

    # 3. Agent：2.0 只有一个统一的 Agent 类，没有 ReActAgent 子类了
    agent = Agent(
        name="hello",
        sys_prompt="你是一个乐于助人的助手，可以执行命令查看环境。",
        model=model,
        toolkit=toolkit,
    )

    # 4. 流式消费：2.0 是 await reply_stream + async for
    async for event in agent.reply_stream(UserMsg("user", "用一句话告诉我当前操作系统是什么。")):
        # 只打印文字增量，其它事件（思考/工具调用）先忽略
        kind = event.type.value
        if "text_block_delta" in kind:
            print(event.text_delta, end="", flush=True)
    print()  # 换行


if __name__ == "__main__":
    asyncio.run(main())
```

运行：

```bash
python code/w00/hello_agent.py
```

**预期输出**：Agent 会调用 Bash 跑个 `uname` 之类的命令，然后给出一句类似"你当前的操作系统是 macOS（Darwin 25.2.0）"的回答，文字是逐字流式打印的。

如果看到这一幕，你的环境就通了。后面 12 周，我们把这个"能用工具"的小东西，一步步变成一个多 Agent 协作平台。

> 如果报错 `KeyError: 'DASHSCOPE_API_KEY'`，说明环境变量没设；如果报 `ModuleNotFoundError`，说明虚拟环境没激活或 agentscope 没装。先解决再往下。
